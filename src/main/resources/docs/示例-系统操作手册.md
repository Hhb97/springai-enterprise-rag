# 后端管理系统操作手册

## 用户管理

### 创建新用户
1. 登录管理后台，进入「用户管理」模块
2. 点击右上角「新增用户」按钮
3. 填写用户名、邮箱、手机号
4. 分配角色（管理员 / 普通用户 / 只读用户）
5. 点击「确认」完成创建

### 重置用户密码
1. 在用户列表中找到目标用户
2. 点击操作栏「重置密码」
3. 系统会生成临时密码并发送到用户邮箱
4. 用户首次登录后需修改密码

## 角色权限

### 角色说明
- **超级管理员**：拥有所有权限，可管理系统配置
- **管理员**：可管理用户和数据，不能修改系统配置
- **普通用户**：可查看和编辑自己的数据
- **只读用户**：仅可查看数据，不能编辑

### 权限配置
进入「系统设置」→「角色管理」，选择角色后勾选对应权限模块。

## 数据导入导出

### 批量导入
1. 下载模板文件（支持 Excel / CSV）
2. 按模板格式填写数据
3. 上传文件，系统自动校验
4. 确认无误后点击「执行导入」

### 数据导出
1. 在列表页面设置筛选条件
2. 点击「导出」按钮
3. 选择导出格式（Excel / CSV / PDF）
4. 等待生成完成后下载

## 常见问题

### Q: 忘记管理员密码怎么办？
A: 联系超级管理员重置，或通过服务器命令行执行 `python manage.py reset_admin_password`

### Q: 导入数据时提示格式错误？
A: 请确认文件编码为 UTF-8，日期格式为 YYYY-MM-DD，必填字段不能为空。

### Q: 如何查看操作日志？
A: 进入「系统设置」→「操作日志」，可按时间、用户、操作类型筛选。
